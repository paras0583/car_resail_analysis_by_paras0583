🚗 Car Resale Price Prediction
📌 Overview

This project focuses on predicting the resale price of cars using machine learning techniques. The goal was to understand how different factors such as car brand, manufacturing year, and other attributes influence the resale value and to build a model that can estimate prices accurately.

Along with model building, detailed exploratory data analysis (EDA) was performed to uncover useful insights and patterns in the dataset, which are documented in the EDA notebook.

🎯 Objectives

Analyze car resale data to identify key price drivers

Perform exploratory data analysis to understand trends and relationships

Build a regression model to predict car prices

Evaluate model performance and interpret results

📊 Exploratory Data Analysis

The EDA process included:

Data cleaning and preprocessing

Visualizing distributions and correlations

Identifying important features affecting price

Observing market trends

All analysis steps are available in the EDA file.

⚙️ Model Approach

A regression model was trained to learn patterns from historical data and predict resale prices. Feature selection and preprocessing were applied to improve performance.

📈 Results

The model is able to provide reasonable price estimates based on input features and demonstrates how machine learning can be applied to real-world market prediction problems.
